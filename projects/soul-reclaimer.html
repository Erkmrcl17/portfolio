Soul Reclaimer｜2D 遊戲

使用 Unity 與 C# 製作的 2D 遊戲作品。

類型遊戲開發

遊戲概念

Soul Reclaimer 是一款以速度與尋寶為核心的 2D 遊戲。玩家必須在時間結束前探索地圖、收集寶藏並擊敗敵人。遊戲包含森林、沙漠與雪地三個區域，每個區域都有不同難度與挑戰。

角色與敵人設計

玩家角色支援前、後、左、右四方向移動，讓 2D 遊戲呈現接近 3D 的動態感。敵人包含接觸傷害型、主動追擊型，以及會發射泡泡與追蹤物的 Boss。

關卡設計

  • Forest Zone：2 分鐘內擊敗約 20 個敵人並收集寶藏。
  • Desert Zone：面對 7 個具有不同攻擊範圍與模式的敵人。
  • Snow Zone：最終關卡，需擊敗兩個 Boss 與剩餘敵人。

我的貢獻與使用技術

本作品標示為「2D GAME BY 李麗恩」。遊戲整體概念與 UI 設計由我自行發想，並使用 Unity 與 C# 製作，涵蓋角色移動、敵人行為、Boss 機制、地圖關卡與遊戲流程設計；後端部分則在學長的協助下完成。
